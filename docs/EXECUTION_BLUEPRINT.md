# Zero-to-100 Execution Blueprint (Minimal + High Agency)

## 1) Team Topology (Lean)

## Core Team (Week 1–4)
- **Product/Founder (1):** scope control, pricing, customer calls.
- **Full-stack Engineer (1–2):** Vite frontend + Vercel functions.
- **Backend/Infra Engineer (1):** provider integrations, security, observability.
- **Growth Operator (1):** acquisition channels + lifecycle campaigns.
- **Customer Ops (1):** support, abuse triage, refunds/escalation.

## Optional Part-Time
- Designer (brand + UI pass)
- Legal advisor (TOS/privacy/refund)

---

## 2) Branding & Positioning

### Brand Strategy
- **Positioning:** “Fastest way to fund, rent numbers, and run SMM from one place.”
- **Personality:** blunt, reliable, fast, no fluff.
- **Promise:** clear pricing, immediate status, transparent history.

### Brand Components
- **Name candidates:** Owlet Connect, OutletFlow, StackSignal.
- **Tagline options:**
  - “One wallet. Three workflows. Zero friction.”
  - “Ship campaigns, not complexity.”
- **Voice style:** direct, action-first, short sentences.

### Visual Direction (Minimal)
- Base palette: charcoal + white + one accent (electric blue or emerald).
- One sans-serif family, two weights max.
- Dense, clear tables and status chips.
- No decorative illustrations in V1.

---

## 3) Pricing & Monetization

### Model
- Wallet pre-funded model.
- Margin per provider operation:
  - 5SIM rental margin,
  - SMM service margin,
  - optional top-up processing fee pass-through.

### Starter Pricing Approach
- Default markup bands by category/country.
- Auto-disable low-margin SKUs.
- Offer “Pro” volume discounts only after retention is proven.

---

## 4) Go-To-Market Strategy

## ICP Focus (first 30 days)
- Solo marketers, small agencies, creators running high-frequency social workflows.

## Channel Plan
1. **Direct outreach:** Telegram/Discord/X communities.
2. **Micro-influencer affiliates:** 10–20 operators with rev-share codes.
3. **Founder-led demos:** Loom + short onboarding tutorials.
4. **Content engine:** “how to” posts tied to conversion pages.

## Offer Strategy
- First top-up bonus (time-bound).
- “Fast refund if provider fails” trust promise.
- Weekly leaderboard for affiliates.

## Funnel Targets
- Landing → signup: 8–12%
- Signup → funded: 35%+
- Funded → first order: 45%+

---

## 5) Ops Runbooks

### Support SLAs
- Business hours first response: <10 minutes.
- Payment issues: escalate in <5 minutes.
- Provider outage banner in app within 3 minutes.

### Refund Policy (Operational)
- Auto-refund if provider rejects after wallet debit.
- Manual review queue for disputed outcomes.
- Immutable notes in audit log.

### Incident Response
- Severity model (SEV1/2/3).
- Decision owner per incident.
- Postmortem within 48 hours.

---

## 6) 14-Day Tactical Sprint Plan

### Day 1–3
- Infrastructure setup + auth + wallet skeleton.
- Payment flow in sandbox.

### Day 4–6
- 5SIM integration + rental UX.
- Logging and idempotency hardening.

### Day 7–9
- Owlet SMM services + ordering.
- Transaction history + notifications.

### Day 10–12
- Admin tools + support workflows.
- Private beta onboarding (10–20 users).

### Day 13–14
- Bug fixes, margin tuning, launch assets.
- Soft launch + daily metric review cadence.

---

## 7) What to Ignore (for speed)
- Native mobile apps.
- Heavy animation/UI polish.
- Multi-language/localization.
- Complex coupon system.
- Enterprise roles/permissions.
